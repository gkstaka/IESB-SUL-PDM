# gestao-financeira

App de controle financeiro pessoal feito em React Native / Expo como prática de PDM.

Precisa da [`gestao-financeira-api`](../gestao-financeira-api) rodando pra funcionar.

## Funcionalidades

- Login e cadastro com JWT
- Listagem de transações com filtro por mês, ano ou histórico completo
- Adicionar, editar e excluir transações (editar/excluir via long press)
- Gerenciar categorias personalizadas
- Resumo com gráfico de pizza por categoria e saldo do período
